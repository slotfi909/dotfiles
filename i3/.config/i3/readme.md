Save screenshots to a file
    Shortcut	Action
    Print	Screenshot entire screen
    Super + Print	Screenshot active window
    Shift + Print	Select a region to capture

Copy screenshots to clipboard
    Shortcut	Action
    Ctrl + Print	Copy entire screen
    Ctrl + Super + Print	Copy active window
    Ctrl + Shift + Print	Select region and copy

Screenshots saved to files go into ~/Pictures/.
